DEXCORE 1.8 R21 - PS4 13.52 testing build

1. Fully reboot the PS4 and load R21 with Write plugin files to HDD enabled.
2. Extract DEXCORE-1.8-R21-Game-Addons.zip on a computer.
3. Use FTP to replace /data/hen/cheats/runtime with data/hen/cheats/runtime from this pack. Install the updated pack together with the BIN.
4. Launch a game. Open Settings > DEXCORE > Game Addons and turn Cheats On.
5. Hold OPTIONS for one second to open Game Addons. Select a trainer and individual options, resume the game, then return and refresh to check status.
