Download BIN only · Pack checksum · Installation and testing instructions

Fully reboot and load R17 with Write plugin files to HDD enabled. On a computer, extract the pack and use FTP to copy data/hen/cheats/runtime to /data/hen/cheats/runtime. Launch a game, then open Settings → DEXCORE → Cheats & Patches. Select a trainer, enable cheats and choose options. Resume the game to process requests; return and refresh to check status.

Hardware testing required: native builds and host checks passed, but this release has not been tested on a PS4. The 5,747 trainer variants include duplicate source entries; conversion does not guarantee compatibility. One-shot buttons are not reversible and do not continuously freeze values.
