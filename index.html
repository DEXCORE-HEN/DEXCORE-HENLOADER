1.8 / PS4 TESTING

Game Addons addressing update.

DEXCORE 1.8 R24 adds memory-map section addressing and validated absolute addresses while retaining expected-byte checks for code patches and rollback protection. Game Addons refreshes automatically once per second and stays visible but greyed out when no game is running. Hold OPTIONS for one second to open Game Addons while Cheats is On and a game is running. The single Cheats switch remains inside Game Addons. Individual cheats start Off for each new game session.

Download 1.8 R24 BIN + Game Addons data pack · 4.93 MiB

Download BIN only · Pack checksum · Installation and testing instructions

Fully reboot and load 1.8 with Write plugin files to HDD enabled. On a computer, extract the pack and use FTP to replace data/hen/cheats/runtime to /data/hen/cheats/runtime. Launch a game, then open Settings → DEXCORE → Game Addons. Turn Cheats On there. Hold OPTIONS for one second to open Game Addons, then select individual options. The compatible trainer with the most eligible options is selected automatically. Resume the game to process requests; return to see status update automatically. Install the new BIN and R24 runtime data together; older BINs cannot read the new trainer format.

Hardware testing required: native builds and host checks passed, but this release has not been tested on a PS4. 44,983 source options pass conversion, 1,308 more than R23. The 5,747 trainer variants include duplicate source entries; these counts do not establish hardware compatibility. Unsupported master formats and extended address schemes remain disabled. One-shot buttons are not reversible and do not continuously freeze values.
