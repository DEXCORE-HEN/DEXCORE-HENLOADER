Game Addons integration.

DEXCORE 1.8 R19 keeps one Cheats On/Off toggle inside Game Addons, adds System Information display fallbacks, and retains one-second hold OPTIONS access. Native cheat execution uses exact title/version matching, reversible toggles and one-shot buttons. All cheats start Off for each new game session. Download BIN only · Pack checksum · Installation and testing instructions

Fully reboot and load 1.8 with Write plugin files to HDD enabled. On a computer, extract the pack and use FTP to copy data/hen/cheats/runtime to /data/hen/cheats/runtime. Launch a game, then open Settings → DEXCORE → Game Addons. Open Settings → DEXCORE → Game Addons and turn Cheats On there. Hold OPTIONS for one second to open Game Addons, then select individual options. The first compatible trainer is selected automatically. Resume the game to process requests; return and refresh to check status.

Hardware testing required: native builds and host checks passed, but this release has not been tested on a PS4. The 5,747 trainer variants include duplicate source entries; conversion does not guarantee compatibility. One-shot buttons are not reversible and do not continuously freeze values.
